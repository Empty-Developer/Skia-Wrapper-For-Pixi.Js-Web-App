A web-based graphics editor built with React, Next.js TypeScript, PixiJS, and Google Skia (CanvasKit WASM).

The main goal of the project is to demonstrate how a PixiJS scene graph can be traversed, converted into Skia drawing commands, rendered through CanvasKit, and exported to PDF.

Instead of relying on traditional canvas screenshots, the application introduces a custom rendering layer that synchronizes PixiJS objects with Skia primitives.
