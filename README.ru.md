# Skia Упаковка Для Pixi.Js Web-Приложение

![Platform Preview](/img/img.png)

Этот проект исследует неочевидную идею: использование двух совершенно разных графических движков в одном веб-приложении.

**[Pixi.js](https://pixijs.com/)** (устаревшая версия, режим Canvas 2D) обрабатывает интерактивный холст - рисует фигуры, управляет иерархией сцены и реагирует на события указателя в реальном времени.

**[CanvasKit WASM](https://skia.org/docs/user/modules/canvaskit/)** (Google Skia, скомпилированная в WebAssembly) используется исключительно в качестве механизма экспорта. Класс `convertPixiContainerToSkia` обходит граф сцены Pixi.js в реальном времени, считывает геометрию и преобразование каждого объекта и перерисовывает его с помощью API холста Skia - обеспечивая высококачественный экспорт в PDF, соответствующий тому, что пользователь видит на экране.

В результате получается простой, но технически интересный редактор дизайна, который может экспортировать свой холст в векторный/растровый PDF.

## Архитектура

### Менеджер сцен - `PixiManager`

`PixiManager` управляет экземпляром `Application` в Pixi.js. Он инициализирует 2D-рендерер Canvas (`forceCanvas: true`) и предоставляет три публичных метода, используемых слоем React:

- **`init(container)`** - создает приложение Pixi, добавляет элемент canvas и загружает пустую сцену.
- **`loadScene(sceneType)`** - очищает сцену и загружает либо пустой холст (допускаются фигуры), либо предустановленный заблокированный макет (`scene1` / `scene2`).
- **`addRandomShape()`** - добавляет прямоугольник или эллипс случайного размера, цвета и поворота. Блокируется при загрузке предустановленной сцены.
- **`destroy()`** - завершает работу приложения Pixi и освобождает ресурсы GPU/памяти.


### Оболочка Skia - `convertPixiContainerToSkia`

`convertPixiContainerToSkia` принимает экземпляр `CanvasKit` и предоставляет следующие возможности:

- **`renderContainer(canvas, container)`** - рекурсивно обходит дерево `PIXI.Container`, считывая необработанные геометрические данные каждого объекта `Graphics` и применяя накопленную матрицу преобразования. Фигуры перерисовываются на холсте Skia с использованием соответствующих дескрипторов заливки и обводки.

- **`exportToPDF(container, fileName)`** - экспортирует контейнер в файл `.pdf`. Конвейер экспорта имеет три уровня резервного копирования:

1. **Собственный PDF Skia** (`SkPDF` / `CreatePDFWStream`) - сначала используется, если сборка WASM предоставляет такую ​​возможность.

2. **Строка SVG** - если изображение Skia содержит функцию `toSVGString()`, SVG-файл встраивается в документ jsPDF.

3. **Растеризация HD** - рендеринг с 4-кратным увеличением масштаба на поверхность Skia, расположенную вне экрана, считывание данных в виде необработанных пикселей RGBA, отрисовка на временном `<canvas>` и встраивание в jsPDF в формате PNG.

### Взаимодействие компонентов

Компоненты React не обмениваются состоянием через props или контекст. Вместо этого они взаимодействуют посредством пользовательских событий `window`:

| Событие | Направление | Полезная нагрузка |
|---|---|---|
| `add-random-shape` | Боковая панель → Редактор | — |
| `switch-scene` | Боковая панель → Редактор, Боковая панель | `{ scene: string }` |
| `request-pdf-export` | Боковая панель → Заголовок | — |
| `trigger-pdf-export` | Заголовок → Редактор | `{ fileName: string }` |

Это позволяет каждому компоненту независимо монтироваться и избегать передачи состояния по всей верстке страницы.

## Начало работы

**Предварительные условия:** [Bun](https://bun.sh/) или Node.js ≥ 18 с npm/pnpm.

```bash
# 1. Перейдите в каталог wrapper
cd wrapper

# 2. Установите зависимости
bun install
# или: npm install

# 3. Запустите сервер разработки
bun dev
# или: npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в вашем браузере.

> **Примечание:** CanvasKit WASM загружается с CDN (`unpkg.com`) отложенно при первом подключении редактора. При экспорте в PDF будет отображаться всплывающее сообщение «Загрузка…», пока не завершится загрузка исполняемого файла WASM (~8 МБ). Последующие экспорты в рамках одной сессии выполняются мгновенно.

## Как работает преобразование Pixi → Skia

Pixi.js хранит геометрию в массиве `GraphicsData` для каждого объекта `Graphics`. Каждая запись содержит:

- Дескриптор **shape** - массив `точек` PIXI.Rectangle, `PIXI.Ellipse` или полигонов.

- **fillStyle** - цвет (в виде упакованного целого числа) и альфа-канал.

- **lineStyle** - цвет, альфа-канал и толщина обводки.

`SkiaRenderer` считывает эти необработанные данные и сопоставляет их с эквивалентами Skia:

| Геометрия Pixi | Вызов Skia |
|---|---|
| `PIXI.Rectangle` | `canvas.drawRect(XYWHRect(...))` |
| `PIXI.Ellipse` | `canvas.drawOval(XYWHRect(...))` |
| Многоугольник / линия | `Path.moveTo / lineTo`, `canvas.drawPath(...)` |

Цвета преобразуются из упакованных 24-битных целых чисел в нормализованный `Float32Array([r, g, b, a])`, как того требует API рисования Skia.

Преобразования объектов применяются путем чтения матрицы `localTransform` из каждого `PIXI.DisplayObject` и вызова `canvas.concat([a, c, tx, b, d, ty, 0, 0, 1])` — в соответствии с компоновкой аффинного преобразования 2D Pixi.
